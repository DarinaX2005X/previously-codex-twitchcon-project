# Local SQLite storage

`createStorage({path,now,encryptionKey,keyVersion})` returns `repository`, `sessions`, `budget`, and a separate `tokenVault` for the auth adapter only. `now` returns UTC epoch milliseconds. Timeline ranges remain session-relative milliseconds. Runtime must hold its single-instance lock before opening the file. Every method is synchronous; awaiting a method is supported, but no callback may do network IO inside a transaction.

The database uses DELETE journaling, foreign keys, and secure deletion. Back up the SQLite file **only after stopping the instance**; restore the matching environment encryption key separately. Losing or replacing that key does not reset saved credentials: opening the vault fails with `key_setup`.

`ensureChannel` / `createSession` establish scope. `ingest(event,{sources,jobs,outbox})` saves evidence and effects in one deduplicated transaction. All IDs, reads, leases, and edits require the same channel/run scope. `saveEntity` stores typed domain records in the normalized `entities` table: claims, relations, chapters, current state, presentations, lore, moments, media, playbacks, provider caches, and exports share dependency invalidation. Entity IDs and source IDs must share one namespace. A media record must supply its conservative capture start/end range.

Before a provider call, `registerGeneration(ticket,entityId)` saves all exposed inputs. `commitStory` rejects stale epochs, source revisions, owner revisions, locks, and unsupported claims. Candidates are immutable and initially unsafe. `markCandidateSafe` requires both moderation and PII approval. `publishEligible` selects the newest matured safe candidate without waiting for a newer draft. Domain adapters remain responsible for strict shared schema validation, meaningful story decisions, and public DTO projection. The stored patch is not itself a public DTO.

`invalidate(scope,target,{idempotencyKey,reason})` tombstones matching inputs, clears event bodies and all derived bodies, cancels in-flight work, revokes candidate pointers, and queues priority retract atomically. Reason text is hashed for idempotency but is not saved. Receipts contain IDs only. File unlink happens outside the transaction after media is hidden. `editEntity` preserves existing lineage, locks model overwrites, withdraws old candidates, and queues retract. Owner-reviewed replacement candidate creation is a separate domain workflow.

Use `enqueueJob`/`claimJob`/`renewJob`/`finishJob` and matching outbox methods. The lease token changes each claim; an expired worker cannot finish a replacement worker's claim. `unknown_outcome` is terminal until an explicit owner resolution; do not supply `nextAtMs` for an ambiguous network effect. `preparePublication` assigns a persistent sequence once; a retry reuses it. A publisher must produce a fresh safe DTO after privacy invalidation, never relabel an old body. `recordRemoteArtifact` preserves cleanup-only clip IDs after a stale response.

Budget ceiling is $4.50, retaining $0.50 from the user's $5 limit as headroom. Paid work starts disabled. Only final-test orchestration may enable it. Reserve a conservative maximum in micro USD before each new live request, settle known actual cost, and release only known-unsent requests. Unknown outcomes stay reserved. Replay reservations always fail. These primitives make no provider calls.
