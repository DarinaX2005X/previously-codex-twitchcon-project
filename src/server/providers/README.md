# Provider, capture and media boundary

All development evidence here uses authored adapters. No live OpenAI request, real microphone permission, browser/OBS audio-device compatibility, or Twitch download has been verified. The media test does decode its own synthetic standalone WAV using the installed FFmpeg and exercises a local HTTP Range endpoint.

## Integration

- Construct one `ProviderTransport` with the existing persistent `BudgetStore`, `runId`, server key, and explicit `externalCallsEnabled`. A key alone cannot enable dispatch. Replay and a disabled budget never call `fetch` or open a Realtime socket. Every HTTP attempt reserves independently; ordinary success, failure, and timeout retain the full conservative allowance. Observed Luna cost above allowance settles the higher amount and disables paid mode through BudgetStore. No expensive model fallback exists.
- `OpenAIStoryProvider.propose` uses `gpt-6-luna`, strict Responses JSON schema, `store:false`, no tools, 1,024 output tokens, and a 25-second timeout. There is at most one schema repair with unchanged evidence. All visible packet references must occur in the registered ticket. `review` separately checks semantic grounding. A provider result is not a publication decision.
- `present` requires the actual accepted `claimRefs` and returns separate EN/RU `PresentationWithCurrent` objects. Title, summary, goal/change/now are checked individually for privacy, moderation and faithful translation. Current fields have no invented timing; runtime supplies authoritative source time. Missing claim roles remain null. An oversized grounding review splits into separately budgeted checks against the relevant supplied supports without changing the registered exposure set.
- `proposeLore(packet,phrases,safety,signal)` accepts at most five `{id,term,aliases?}` observations and returns reviewed safe candidates plus `heldIds`. Terms and aliases must occur in the same registered packet. Only exact active speech/owner references can establish origin; repetition, chat guesses and first observation cannot. Each candidate passes text safety and an independent origin/ambiguity review. Runtime must select observations whose refs are already in the ticket, recheck privacy before applying results, and preserve **all ticket inputRefs as exposureRefs**, separately from exact originRefs/supports. Held lore never blocks an existing safe recap.
- The full JSON request must fit 7,600 UTF-8 bytes. Bytes are a conservative bound on text tokens, including RU/code, schema, instructions and wrapping. `storyRequestBytes(packet,revision,true)` exposes the exact repair envelope. Core must trim **before** ticket creation; an escaped packet (`JSON.stringify(JSON.stringify(packet))`) of at most 4,000 UTF-8 bytes fits even with a 160-character session ID and maximum safe base revision. A too-large request holds before dispatch.
- `SafetyService.inspectBatch([{id,text}])` returns independently sanitized fields and safety statuses. The real contextual adapter batches up to 30 short fields / 3,800 serialized text bytes; actual redactions get a second contextual check. Moderation sends an array in one request. `inspect` returns `{text,safety}`. Callers must use returned text. The narrower `check` port holds if redaction changed the supplied text, since that port cannot return its replacement. `prepareEvidence` scans every text field but must run before a generation ticket is frozen; do not silently change registered inputs. No raw evidence appears in provider errors.
- `OpenAITranscriptionProvider` sends an independent mono PCM16 WAV as multipart `file`, model `gpt-transcribe`, and optional `languages[]`. It preserves original transcript languages and uses chunk timestamps. Obvious silence is skipped locally; missing provider confidence remains `null`, not a fabricated score. Music detection and real STT quality remain unverified.
- `OpenAIRealtimeNarrationProvider` is opt-in. Supply an `approved(text,language)` gate for current published text and lineage. It checks before request and before returning audio, uses one isolated Realtime response, and rejects transcript mismatch. Supply its returned WAV to the private media lifecycle. Caption fallback remains usable when narration fails. The UI must disclose AI voice.

## Capture and audio jobs

`CaptureController` accepts injected media and transport APIs. `start`, `resume`, `takeover`, `pause`, `offline(endedOffsetMs)`, `dispose`, state subscription, and actual RMS level are available. `createBrowserCaptureEnvironment`, `createCaptureHttpTransport(csrf)` and `useCapture` connect it to a browser. Start requires user action. Privacy pause stops the track, aborts uploads, drops incomplete samples and the local queue; offline stops capture after flushing a valid partial WAV bounded by the session end. Permission cancellation stops any late-granted track. The worklet is served at `/worklets/pcm-capture.js`.

Mount `createAudioRouter(service, ownerMiddleware)` at `/api/owner` using existing origin/owner/CSRF/idempotency protection. It accepts a bounded multipart body with exactly `metadata` and `file`. Metadata includes the signed lease token, browser ID, session ID, epoch, sequence, sample rate, interval, and SHA-256. A signed server anchor and actual WAV header/duration constrain timestamps. Storage owns sequence/hash deduplication, capture/privacy fences and atomic `speech.transcribed` acceptance.

Capture lease/renew/pause requests use storage `runIdempotentControl` so a repeated mutation returns its original signed anchor and never increments the capture epoch twice. New chunk sequences cannot overlap previously accepted intervals. A later sequence may skip an interval to represent an upload gap.

Create `AudioIntakeService` with repository, secret, private raw directory, transcription, safety, clock, and optional `onSource`/`onGap`. Register the scheduler lane with `kinds:['stt']`, `concurrency:2`, and `execute:(job,signal)=>service.execute(scope,job,signal)`. Retry only explicit 429/5xx results, at most three attempts within 60 seconds of intake; timeouts retain the reservation and become a gap. Raw files are removed on terminal completion. Run `cleanup()` on startup and every 30–60 seconds for the two-minute TTL. Storage commits are fenced even if an aborted provider later responds.

## Private media

`PrivateMediaCache` requires a directory outside public/static roots, exact authorized download hosts, and a current `visible(record)` gate. URL redirects are checked individually. Downloads are capped at 80 MB; default cache is 512 MB / 12 files. FFprobe checks type, duration and streams, and FFmpeg performs a full decode before `ready`. Both processes use restricted demuxers and `file,pipe` protocols, preventing embedded playlists from fetching external URLs. No arbitrary user-URL proxy is exported. Failures expose generic error codes, not signed download URLs.

Mount `createMediaRouter(cache, capabilityMiddleware)` at `/api/media`. The middleware must authorize the scoped owner or overlay capability. Every full or Range request rechecks visibility; response streams also revalidate and stop synchronously on local revoke. `protect(id,untilMs)` prevents eviction during active playback; privacy revoke always wins. `onRevoke` must also cancel browser playback and queued scenes. A browser that already received bytes still needs the shared visibility lease; previously downloaded outside copies cannot be recalled.

Official interfaces verified during implementation: [Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [file transcription](https://developers.openai.com/api/docs/guides/speech-to-text), [Realtime response.create](https://developers.openai.com/api/reference/resources/realtime/client-events#response.create). Documentation verification does not establish account model access.
