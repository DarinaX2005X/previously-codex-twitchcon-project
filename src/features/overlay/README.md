# Broadcast scene

`OverlayPage({client})` is the transparent 1920×1080 OBS source. The application owns capability exchange and routing. `client` implements `OverlayClient` from `index.ts`; SSE comment heartbeats must call `onHeartbeat`. State polling is two seconds and visibility expires after six seconds without a successful state or heartbeat. Privacy/cancel/reset notifications clear the scene before revalidation. The server owns trigger deduplication and the one-active/one-pending raid queue.

`ScenePlayer({plan,timeMs,playing})` renders a captured canonical plan from an external clock. Omit `timeMs` to use its local monotonic playback clock. `ScenePreview` defaults to cropping the 1920 frame to the selected safe footprint; this is useful in a dock or landing. `SceneSummary` reflows the same plan for a narrow settled reading surface. These three components have no trigger or broadcast client. A preview cannot ACK or schedule a live scene.

Optional player props include `channel`, `title`, `resolveMedia(id)`, `reducedMotion`, `soundEnabled` (false by default), `volume`, `onEnded`, `onStatus`, `className`, and `cropToLayout`. `preparedMedia` transfers the already prepared local bundle into the source without a second download. A media resolver only receives IDs present in the plan. The player uses canonical clip in/out and capture time; no URL extraction or pretend poster is used. Narration in `plan.audio` is independent of optional synthesized effects. Video remains muted.

`renderAt(tMs,plan,layout,options)` is a pure seekable frame calculation; `resolveSceneLayout(plan.layout)` chooses an edge-aligned free region before prepare ACK. Its clipping envelope excludes each protected rectangle plus 24 px, including travelling surfaces, blur and shadow. Captions retain 80–96 px type. `sceneTextFits` uses an injected Onest canvas measurement and refuses captions beyond two main lines rather than silently truncating or paging. Preparation can omit a ready clip when the wider text-only composition is necessary. No fitting region produces `layout_required`; excessive wording produces `text_too_long`. Local UI should explain those statuses beside the preview controls. `audio_blocked` requires an explicit browser/OBS audio setup action.

The sequence opens a source aperture, carries only the plan's supported records through a shared-edge assembly, then contracts into the return mark. Goal, change, origin and current-state beats appear only when the plan contains them. A single context record holds on one useful surface; it does not manufacture extra story roles. The pushing second plane exists only for a second supported record, and origin sounds exist only for an actual origin. A 10-second cut can omit the optional origin; a 15-second cut gives reading/narration more time. Reduced motion holds all fitting permitted text on an opaque surface and does not autoplay video. No narration playback rate is increased. `SceneSummary` keeps the actual current beat focal, or the last supported record when no current beat exists, with its original semantic label.

Functional checks live in `tests/overlay`: safe geometry, arbitrary seeks, caption overflow, reduced motion, clip bounds, first-frame readiness and timeout, audio/video cleanup, exact start/end, stale prepare completion, monotonic time, lease expiry, immediate invalidation and completed-ID reconnect. Pixels, actual-speed motion, listening, OBS routing and real media remain separate review evidence. The initial authored replay has no video; it is not evidence of a recorded stream.
