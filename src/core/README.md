# Story domain

`createDomainState`, `reduceDomain(state, event, clock)` and `recoverDomainState` are shared by the local runtime and browser replay. This directory has no Node, network, storage, DOM or wall-clock calls. A `Clock` supplies both epoch time and ISO time. Inputs are normalized events; fixtures are explicitly authored development data.

`reduceDomain` returns a private checkpoint and typed effects. The runtime must atomically commit the checkpoint, source/entity changes, candidate records, generation inputs and durable outbox under the SQLite revision/privacy/editorial fences. It must not call the legacy raw `commitStory` path as a second publisher. Network work begins only after commit and repeats the dependency fence before sending or starting playback. An abort signal is an optimization, not authorization.

`generation.request` contains the immutable ticket, frozen packet and target entity. The packet uses an escaped UTF-8 byte cap of 4,000; the provider additionally bounds the complete request including its schema and instructions. All inputs, including immutable previous-chapter contexts and independent memory records, enter exposure lineage. New claims use generation-specific IDs. Model-proposed paraphrases and causal edges require the separately supplied `GroundingReview`; deterministic checks also reject unknown revisions, chat outcomes, unresolved pronouns and quoted instructions. This is a conservative boundary, not proof of arbitrary semantic truth.

Canonical chapters, current projections and independent memory facts are distinct from immutable publication candidates. At most four live candidates remain per entity. Publication selects the newest matured safe version, even while a newer draft is waiting. Every public sink consumes `selectPublicSnapshot`; `canDispatch` adds the current epoch, candidate and media checks. Holding a result does not advance `asOf`.

Every privacy epoch discards unfinished candidates and generation tickets, including work unrelated to the specific target, to mirror the durable transaction fence. Unaffected published context remains available. Surviving held owner reviews receive new epoch-scoped durable intents; pending clip slots become unavailable instead of blindly repeating an external create request.

Lore has at most one immutable presentation per language and canonical revision, stored in `lorePresentations` and presentation graph nodes. `lore.presentation` accepts only checked wording tied to the exact lore revision, privacy epoch and full input exposure set. Publication selects the current language. Switching language waits for translations of visible confirmed lore; held lore does not block a switch or raid. Owner edits and erasure invalidate both presentations. The canonical origin facts are never supplied by a translation result.

Recent raw sources are capped at 500, memory facts at 64, public chapters at 300, lore at 50, moments/media at 200, reaction windows at 30, and recap playback at one active plus one pending welcome. Historical lineage retains metadata without the raw transcript; SQLite keeps the durable graph and paginated history. The first independent memory fact is retained instead of blending it into a rolling summary. Tombstones and channel term blocks are privacy control state and are never discarded to make a memory limit appear smaller.

Privacy removes bodies and invalidates both support and exposure descendants. Media capture overlap is checked separately from caption evidence. Chapter hiding preserves transcript content but excludes its old evidence from generation. Chat clear quarantines old chat without deleting speech or creating source tombstones. Bans plus actor cutoffs survive unban, while future collection can resume. Clip cleanup effects carry service identifiers for the owner; they never make a late clip playable.

Owner editing is a two-step transaction: `owner.edit` withdraws the public version and records a pending owner statement plus a durable `owner.review.request`; `owner.review` atomically replaces the checked statement, chapter and immutable candidate under owner/source revision and privacy-epoch fences. The review job contains identifiers, not text, and rereads authoritative inputs after restart. Safe edits bypass another hold. Lore has matching edit/review events. Both language versions are withdrawn together; a settings language switch requires a complete checked projection. `settings` applies pause and language semantics before scheduling.

On offline, a final generation replaces an unfinished ordinary request. New accepted tails force another final pass. Finalization before the 240-second deadline requires explicit `tail.drained` and no unresolved accepted speech/chat safety checks; the runtime owns the accepted-STT job count. At the deadline, unfinished processing produces a gap. Late speech safety results cannot silently modify a finalized episode. A finalized local snapshot and its outbox are one transaction; `cloud.ack` separately records the confirmed online revision.

Playback preparation expires after 1.5 seconds without readiness. A start missed by more than three seconds is skipped; a playing scene ends by its absolute clock even if the client disconnects. Queue promotion starts a fresh preparation timeout, and completed trigger IDs remain deduplicated.

`recoverDomainState` accepts the structural hydration DTO supplied by storage. A valid checkpoint is fenced against durable privacy controls. Without one, surviving canonical nodes and published candidates rebuild a conservative projection. Playback is cancelled by default on cold recovery; the running runtime may pass `{resumePlayback:true}` for ordinary reads after performing persisted startup cancellation. A checkpoint contains private evidence and must never be served as a replay export.

`tests/domain/engine.test.ts` covers deterministic replay, eight virtual hours, exact hold boundaries, review failures, editorial and privacy races, moments, lore, queue caps, recovery, closing and separate cloud acknowledgement. These authored tests do not establish real microphone quality, Twitch delivery, semantic model accuracy, browser appearance, or measured audience comprehension.
